# **Project Objective**

The Data Science Students Performance Analysis project aimed to analyze students’ academic performance using Tableau to uncover trends, comparisons, and insights across subjects, age groups, and locations.

The dashboard was designed to provide interactive visual analytics for understanding student marks, top performers, demographic distribution, and subject-wise performance.

---

# **Dataset**

- Student academic performance data
- Subject-wise marks and scores
- Age and demographic information
- Student location and attendance details

---

# **Key Business Questions**

- Which students achieved the highest total marks?
- How does performance vary by age?
- Which locations have the highest number of students?
- How do SQL and Python marks compare?
- Who are the top performers in Excel?
- What is the overall average student mark?

---

# **Process & Methodology**

### **Data Cleaning**
- Removed duplicates and handled missing values
- Standardized student and subject data
- Prepared datasets for Tableau analysis

### **Data Analysis**
- Analyzed subject-wise student performance
- Compared SQL, Python, and Excel marks
- Evaluated age and location-based student distribution

### **Dashboard Development**
- Built interactive Tableau dashboards and KPI cards
- Created charts for performance comparison and trends
- Added filters and visuals for user interaction

---

# **Dashboard Insights**

- Identified top-performing students by total marks
- Analyzed average marks across different age groups
- Compared SQL and Python performance trends
- Visualized student distribution across locations
- Highlighted top performers in Excel
